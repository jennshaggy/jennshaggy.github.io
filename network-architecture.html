Network Architecture & Implementation

Home and small office network design, deployment, and remote management

One box of many - routers, switches, cables, and testing equipment accumulated across multiple deployments

Network security starts at the infrastructure layer. Proper topology, segmentation, and coverage optimization aren't just performance concerns - they're foundational security controls that determine what's reachable, what's isolated, and where the perimeter actually is.

Current Network (Albuquerque, NM)#

Deployed a 3-node TP-Link Deco 6E tri-band mesh network optimized for complete residential coverage with intentional signal boundaries. The ISP-provided router was immediately placed in bridge mode and its hidden hotspot broadcast functionality - designed to extend the ISP's public network into customer homes - was disabled.

ISP router (left) configured in bridge mode, Deco 6E mesh node (right) handling all routing and wireless

Initial deployment - ISP equipment neutered to passthrough only

Network segmentation isolates IoT devices on a separate SSID with distinct credentials. Guest network capabilities were disabled entirely to reduce attack surface. Coverage was validated and optimized using RF heat mapping across the full residence.

Heat map validation - download speeds optimized across interior space, signal intentionally cuts off at property boundary

Key outcomes: Zero dead zones inside the residence. Network signal terminates at the property line - not by accident, but by design. IoT devices cannot reach the primary network. ISP equipment operates as a transparent bridge with no broadcast capabilities.

Remote Network Management (Virginia)#

Fiber-to-the-home (FTTH) mesh deployment across a 3-story, 105-year-old residential structure with solid plaster and stone walls. Coverage optimization required accounting for both horizontal floor-to-floor propagation and vertical signal attenuation through century-old construction.

Mesh node placement optimized for multi-floor coverage in solid construction

Strategic node positioning accounts for wall density and vertical signal path

A second isolated network was configured for home lab operations, running on dedicated infrastructure with no access to the primary residential network. All ethernet infrastructure was custom-built: individual wires stripped and terminated by hand, punched down into a patch panel, and validated with cable testing before deployment.

Patch panel terminations - each cable hand-wired and tested

Punch-down block connections for home lab network runs

Custom-made ethernet cables with hand-crimped connectors - each wire terminated individually

Cable testing validation - confirming continuity and performance before deployment

This network is managed remotely from over 1,800 miles away. Monitoring, configuration changes, and troubleshooting are handled entirely over the network itself - no physical access required.

Network Design Approach#

Networks aren't appliances. They're infrastructure that determines what's accessible, what's segmented, and where trust boundaries exist. Proper deployment requires understanding RF propagation, physical construction constraints, device isolation requirements, and long-term maintainability. The goal isn't just connectivity - it's controlled, segmented, validated connectivity that fails closed when things break.
