Malware Investigation — Multi-Stage Intrusion Analysis

Investigation Summary
Analyzed a multi-stage intrusion progressing from phishing-based initial access through lateral movement to domain compromise. Examined phishing artifacts, endpoint memory, PowerShell logs, and SIEM telemetry to reconstruct attacker behavior across persistence establishment, privilege escalation, credential theft, and ransomware staging. Demonstrated how a single phishing email can escalate into full network compromise when defenses fail at each stage.

Tools Used
Wireshark, Tshark, jq, LNKParse3, Thunderbird, Volatility, Olevba, Elastic Stack (Kibana), Sysmon, Linux CLI

Overview

This investigation tracked a targeted attack against a logistics company across three connected intrusion stages. The attacker used phishing to gain initial access, established persistence through memory-resident malware and scheduled tasks, escalated privileges via UAC bypass, harvested credentials from multiple systems, moved laterally across the network, and ultimately achieved domain-level access before staging ransomware deployment.

Phase 1: Initial Access and Credential Theft

Analyzed phishing email artifact using Thunderbird and extracted malicious shortcut file from attachment. LNKParse3 revealed embedded PowerShell command in LNK metadata. Parsed powershell.json logs with jq showing reconnaissance activity and access to KeePass credential database. Examined capture.pcapng in Wireshark confirming command-and-control traffic and outbound transmission of encoded credential data to external infrastructure.

Phase 2: Memory Analysis and Persistence

Investigated second phishing attempt targeting HR employee using malicious resume document. Applied Olevba to extract VBA macros revealing second-stage payload download. Used Volatility on memory dump to reconstruct process execution tree and identify malicious binary responsible for C2 communication. Identified scheduled task persistence mechanism ensuring attacker maintained access across system restarts.

Phase 3: Privilege Escalation and Lateral Movement

Queried Elastic Stack logs through Kibana to track post-compromise activity. Identified UAC bypass technique used to elevate privileges on compromised system. Tracked download of credential dumping tool from public repository and subsequent credential harvesting. Followed lateral movement across network using stolen credentials and mapped access to network shares containing additional authentication data.

Phase 4: Domain Compromise and Ransomware Staging

Analyzed Sysmon telemetry showing attacker progression to domain-level system. Identified DCSync attack used to replicate domain controller data and extract password hashes from Active Directory. Tracked download of ransomware payload to staging location indicating preparation for encryption-based extortion.

Attack Chain Reconstruction

Initial Access
Phishing emails targeting finance and HR employees

Execution
Malicious shortcuts and document macros triggered PowerShell and payload downloads

Persistence
Scheduled tasks ensured continued access across reboots

Privilege Escalation
UAC bypass obtained elevated privileges for credential access

Credential Access
KeePass databases, credential dumping tools, and DCSync extracted authentication data

Lateral Movement
Stolen credentials enabled access to additional systems and network shares

Command and Control
Multiple C2 channels maintained attacker communication throughout intrusion

Impact
Domain compromise achieved, ransomware staged for deployment

Key Findings

  • Phishing remained effective across multiple employees despite initial compromise awareness
  • Attacker pivoted tactics after first detection, targeting different department with tailored lure
  • Persistence mechanisms deployed immediately after each successful compromise
  • Credential theft occurred at every stage enabling continued access expansion
  • No single defensive layer prevented full progression from phishing to domain compromise
  • Time from initial access to domain compromise demonstrated sophistication and planning
  • Ransomware staging confirmed financial motivation behind intrusion

Detection Opportunities

  • Alert on PowerShell execution originating from archive attachments or shortcut files
  • Monitor access to credential storage including KeePass databases and LSASS memory
  • Detect scheduled task creation by non-administrative processes or from unusual parent processes
  • Flag UAC bypass attempts especially when paired with subsequent privilege-requiring operations
  • Identify lateral movement through unusual authentication patterns or access to administrative shares
  • Alert on DCSync activity from non-domain-controller systems
  • Monitor downloads from public code repositories especially credential dumping or offensive tooling

Lessons Learned

This investigation demonstrated how attackers chain multiple techniques across an intrusion lifecycle. Each stage built on the previous, with credential theft serving as the primary enabler for continued access expansion. Detection at any single phase could have limited impact, but the attack succeeded because defensive gaps existed at every layer. The progression from phishing to domain compromise reinforced that defense requires depth across email security, endpoint protection, access controls, and behavioral monitoring. Single-point failures in any of these areas enabled the attacker to advance.

Additional Security Work

Beyond malware investigations, this section documents hands-on security work including endpoint hardening, SOC operations, detection engineering, and identity defense.

Endpoint Security & Hardening

Hardened Windows 10/11 endpoints against ransomware and persistence. Configured Defender, firewall rules, exploit protection, and application controls. Disabled unnecessary services and reduced attack surface. Implemented secure browser configurations and credential protections. Validated hardening through simulated attack scenarios.

SOC Operations & Incident Analysis

Blue-team analysis performed across multiple platforms including LetsDefend, Hack The Box, and CIAT lab environments. Investigated alerts including malware execution, suspicious PowerShell, and lateral movement. Distinguished true positives from noise using host and network telemetry. Correlated indicators across logs, timelines, and artifacts. Mapped findings to MITRE ATT&CK techniques.

Detection & Security Automation

Built detection logic for phishing, malware payloads, and abnormal execution. Tuned rules to reduce false positives. Applied automation principles to accelerate triage. Explored AI-assisted SOC workflows and alert enrichment in simulated SOC environments.
