Security & Defense

Applied defensive security across endpoints, networks, and cloud environments

This work prioritizes real systems, real telemetry, and real failure modes over theory.

Scope

This section documents defensive security work including:

  • Endpoint hardening and system resilience
  • SOC-style analysis and alert triage
  • Detection logic and security automation
  • Incident documentation and response workflows
  • Identity, access control, and privilege management

Malware Analysis

Live incident investigation case studies from TryHackMe SOC training. Hands-on analysis of phishing attacks, PowerShell execution chains, memory forensics, lateral movement, and domain compromise.

Focus: Multi-stage intrusion analysis, endpoint forensics, SIEM investigation

Endpoint Security & Hardening

Hands-on system defense performed on physical machines and VMs.

  • Hardened Windows 10/11 endpoints against ransomware and persistence
  • Configured Defender, firewall rules, exploit protection, and application controls
  • Disabled unnecessary services and reduced attack surface
  • Implemented secure browser configurations and credential protections
  • Validated hardening through simulated attack scenarios

Primary reference: Operation Hard Dell

SOC Operations & Incident Analysis

Blue-team analysis performed across multiple platforms.

  • Investigated alerts including malware execution, suspicious PowerShell, and lateral movement
  • Distinguished true positives from noise using host and network telemetry
  • Correlated indicators across logs, timelines, and artifacts
  • Mapped findings to MITRE ATT&CK techniques
  • Documented incidents using structured Markdown workflows

Platforms used:

  • LetsDefend
  • Hack The Box
  • CIAT lab environments

Detection & Security Automation

Detection engineering and automation concepts applied in simulated SOC environments.

  • Built detection logic for phishing, malware payloads, and abnormal execution
  • Tuned rules to reduce false positives
  • Applied automation principles to accelerate triage
  • Explored AI-assisted SOC workflows and alert enrichment

Identity & Access Defense

Access control and identity security across lab and organizational contexts.

  • Applied RBAC and least-privilege principles
  • Configured and analyzed AAA / TACACS+ authentication flows
  • Evaluated identity misconfigurations and escalation risks
  • Enforced policy-driven access boundaries

Defensive Networking Concepts

Security controls applied at the network layer.

  • Segmented networks and enforced boundary controls
  • Isolated management, IoT, guest, and private networks
  • Applied firewall and routing logic to restrict lateral movement
  • Designed networks with defense-in-depth principles
