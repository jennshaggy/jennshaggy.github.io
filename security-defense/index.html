Malware Analysis and Incident Reconstruction

The Boogeyman investigations were the final CTFs in TryHackMe's Junior Penetration Tester path. Together, they follow one intrusion from initial access through persistence, memory forensics, lateral movement, and domain compromise.

Boogeyman: Initial Access and Exfiltration

Platform: TryHackMe
Lab: Boogeyman Part 1
Focus: Phishing, PowerShell, credential access, command and control, data exfiltration
Tools: Thunderbird, Wireshark, TShark, jq, LNKParse3, Linux CLI
Artifacts: dump.eml, powershell.json, capture.pcapng

Quick Logistics LLC received a phishing email disguised as a follow-up invoice from a business partner. The attached archive contained a malicious Windows shortcut.

I reconstructed the message in Thunderbird and inspected the shortcut with LNKParse3. Its command line launched PowerShell. Parsing powershell.json with jq showed the next steps: additional downloads, system reconnaissance, credential harvesting, access to a KeePass database, and data staging.

I used the domains and commands from the PowerShell logs to pivot into capture.pcapng. Following the HTTP traffic in Wireshark and TShark exposed remote command execution, returned command output, and encoded data leaving the workstation.

Boogeyman 2: Memory Forensics and Persistence

Platform: TryHackMe
Lab: Boogeyman Part 2
Focus: Spear phishing, memory forensics, command and control, scheduled-task persistence
Tools: Volatility, olevba, Linux CLI
Artifacts: Phishing email, malicious document, memory dump

Quick Logistics was targeted again, this time with a resume sent to Human Resources. The document contained a VBA macro that retrieved a second-stage payload from an external URL.

I used olevba to inspect the macro, then Volatility to reconstruct what happened after the download. The memory image contained the payload path, its execution process, the surrounding process tree, and the additional binary it downloaded.

Further analysis identified the process responsible for command-and-control traffic, including its PID, file path, and remote IP address and port. The attacker then created a scheduled task for persistence. The complete task command was recoverable from memory.

Boogeyman 3: Lateral Movement and Domain Compromise

Platform: TryHackMe
Lab: Boogeyman Part 3
Focus: Persistence, privilege escalation, credential dumping, lateral movement, domain compromise
Tools: Elastic Stack, Kibana, Sysmon, Linux CLI
Artifacts: Elastic SIEM logs, host telemetry

Part 3 moved the investigation into the Elastic Stack. Using centralized Sysmon and host telemetry, I traced the attacker across several systems. With access to an internal email account, the attacker sent another phishing message, this time targeting the CEO.

Queries in Kibana connected the initial payload process to an implanted file, scheduled-task persistence, and outbound command-and-control traffic. The logs also captured a UAC bypass followed by the download of a credential-dumping tool from a public GitHub repository.

The stolen credentials were used to access another machine. From there, the attacker enumerated network shares, opened a remote file, and recovered another set of credentials. Those credentials led to a second machine, where process telemetry identified the parent process responsible for executing the malicious command. Additional account hashes were dumped from that host.

The attacker eventually obtained domain-level access and performed a DCSync attack against Active Directory. Multiple account hashes were extracted. The logs then showed an attempt to download another binary from a remote location. Its intended use was ransomware deployment, but no ransomware execution appeared in the timeframe covered by the available logs.

Detection Engineering and Security Tooling

I built aismon to detect AI-related activity in Windows Sysmon Event ID 1 data. The Python CLI evaluates events against 35 YAML rules across seven behavior categories. I added secure XML parsing, API-key redaction, false-positive tests, schema validation, and automated testing across multiple Python versions.
