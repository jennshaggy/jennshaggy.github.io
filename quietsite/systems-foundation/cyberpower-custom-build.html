CyberPowerPC Custom Build

A custom PC built in 2011, not out of necessity, but because building something teaches you how it works.
Status: Complete

Overview#

In 2010, with some funds from a cookbook advance, the decision was made to build a PC. Not because one was needed — a Mac was already the daily driver. But because building something from components is how you learn what's actually happening under the case.

This wasn't the first build. The first was years earlier, funded with a portion of bat mitzvah gift money, assembled in high school, and used until it aged out. That one taught the basics. This one was built for the experience itself.

Build Specifications#

Built: 2011

  • Case: Thermaltake Element-T Mid-Tower (Purple Trim)
  • CPU: AMD Phenom II X6 1055T Six-Core (2.8 GHz, HyperTransport Technology)
  • Motherboard: Gigabyte GA-870A-UD3 (AMD 870/SB850 chipset, Socket AM3, DDR3 support, USB 3.0, SATA-III, 7.1 audio, GBLAN)
  • Memory: 4GB DDR3/1600MHz Dual Channel (Corsair, 2x2GB)
  • Storage: 1TB SATA-II 7200RPM HDD (16MB cache)
  • Graphics: ATI Radeon 2100 (integrated)
  • Optical Drive: LG WH10-LS30K 10X Blu-Ray Rewriter (Red)
  • Power Supply: 450W Standard
  • Cooling: AMD-certified CPU fan and heatsink, case fan included
  • Audio: High-definition onboard 7.1 audio
  • Networking: Gigabit LAN
  • Extras: Internal 12-in-1 flash media reader (red), 4GB Patriot USB flash drive included
  • Peripherals: Xtreme Gear keyboard (black) and optical USB gaming mouse

And yes — it had a glowing green light. That mattered in 2011.

Objectives#

  • Source compatible components across CPU, motherboard, memory, and storage
  • Assemble from bare components to POST-ready system
  • Validate thermal performance and system stability
  • Confirm all peripherals and expansion devices functional

Work Performed#

Component Selection#

Parts were selected for compatibility, not cutting-edge performance. The AMD Phenom II X6 was a six-core CPU at a time when quad-cores were standard — overkill for the intended use, but the headroom was there if needed. The Gigabyte motherboard supported USB 3.0 and SATA-III, which were still relatively new standards in 2011.

Memory was kept modest at 4GB DDR3. The integrated Radeon 2100 graphics were sufficient — no discrete GPU needed. This wasn't a gaming rig. It was a build for the sake of building.

Assembly#

Standard build sequence:

  • Motherboard installed in case, standoffs positioned correctly
  • CPU seated in Socket AM3, retention lever locked
  • Thermal paste applied, heatsink and fan mounted
  • RAM installed in dual-channel configuration
  • Power supply mounted, all power connectors routed and attached (24-pin ATX, 8-pin CPU, SATA power)
  • Storage drive installed in drive bay, SATA data cable connected to motherboard
  • Optical drive installed, connected via SATA
  • Front panel connectors attached (power button, reset, USB, audio)
  • Cable management completed

First Boot#

Power button pressed. Fans spun up. POST completed. BIOS loaded. All components detected — CPU, RAM, storage, optical drive. No debug LEDs, no beep codes. Clean boot on first attempt.

That's the payoff. When you've sourced every component, seated every connector, and routed every cable yourself, a successful POST isn't luck — it's validation.

Outcome#

System was used for approximately one year. As a Mac user at the time, the PC saw light use — more proof-of-concept than daily driver. Eventually sold, nearly unused, to someone who would actually run it daily.

The specs weren't impressive. The use case wasn't critical. But that was never the point.

Why It Matters#

You don't learn how systems work by buying them pre-assembled. You learn by sourcing parts, verifying compatibility, assembling from components, and troubleshooting when something doesn't POST.

This build wasn't about the hardware. It was about understanding what a motherboard does, why RAM timings matter, how power delivery works, and what happens between pressing the power button and seeing a BIOS screen.

That's knowledge you can't get from a product page.
