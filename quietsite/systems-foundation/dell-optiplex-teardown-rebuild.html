Dell OptiPlex — Complete Teardown & Rebuild

Full system disassembly, component-level documentation, and methodical reassembly. Every screw tracked, every part identified.
Status: Complete

Overview#

A Dell OptiPlex Tower Plus 7020 was disassembled down to the motherboard, with every component removed, inspected, and documented. The goal wasn't just to take it apart — it was to understand the architecture, validate compatibility, and reassemble it with full confidence in every connection.

This is the kind of work that builds systems intuition. You can't troubleshoot what you don't understand, and you can't understand it without taking it apart first.

Objectives#

  • Complete teardown to motherboard level
  • Component identification and specification documentation
  • ESD-safe handling and workspace discipline
  • Methodical reassembly with validation at each step
  • Post-build functional verification

System Specifications#

Platform: Dell OptiPlex Tower Plus 7020 (D31M motherboard)

Processor#

  • CPU: Intel Core i5-14500 (14th Gen)
  • Cores: 14 (6 P-cores + 8 E-cores)
  • Base Clock: 2.6 GHz
  • Max Turbo: 5.0 GHz
  • Cache: 24 MB Intel Smart Cache
  • TDP: 65W
  • Socket: LGA1700 (Land Grid Array — pins in socket, not CPU)
  • Integrated Graphics: Intel UHD Graphics 770

Memory#

  • Installed: 16 GB DDR5 UDIMM (single-channel)
  • Speed: 4400 MHz
  • Slots: 4 DIMM slots (supports DDR5 only)
  • Upgrade Path: Second module in DIMM Slot 2 for dual-channel operation

Storage#

  • Primary: M.2 NVMe SSD (PCIe Gen4)
  • M.2 Slots: 4 total (supporting both PCIe and SATA M.2 drives)
  • SATA Ports: 6 onboard

Power Supply#

  • Wattage: 260W
  • Efficiency: 80 Plus certified
  • Type: Modular
  • Connectors: 8-pin ATX, 4-pin CPU, SATA, PCIe

Expansion#

  • PCIe Slots: 1x PCIe x16, 1x PCIe x4, 1x PCIe x1
  • M.2 Expansion: 1x M.2 2230 slot for WiFi/Bluetooth combo card

Connectivity#

  • USB: 3x USB 2.0, 6x USB 3.2 Gen 1, 1x USB 3.2 Type-C
  • Display: 1x DisplayPort
  • Audio: 1x Universal Audio Port
  • Network: Onboard Gigabit Ethernet + WiFi 6/Bluetooth module

Work Performed#

Pre-Teardown#

Before disassembly, the system was powered on to verify POST and boot behavior. Once confirmed functional, the system was powered down and the workspace prepared:

  • ESD-safe surface established
  • Component containers organized for screws and small parts
  • Documentation tools ready (camera, notes)
  • Service manual and motherboard diagram referenced

Disassembly Sequence#

Components were removed in reverse dependency order to avoid unnecessary handling:

  1. Case cover — Screws documented, cover removed and set aside
  2. CPU cooler/fan assembly — Thermal interface inspected, fan connector noted
  3. RAM modules — DIMM clips released, modules removed by edges only (no contact with gold fingers)
  4. M.2 NVMe SSD — Retention screw removed (critical — system will not boot without it), drive lifted from socket, thermal pad left intact
  5. CPU — LGA1700 socket lever released, retention mechanism lifted, CPU removed by aluminum heat spreader only (no contact with underside pins)
  6. Power supply cables — 8-pin ATX, 4-pin CPU, SATA, and PCIe connectors documented and removed from motherboard and cable routing clips
  7. Power supply unit — Three rear screws removed, PSU slid forward and lifted out

At this point, the motherboard was fully exposed with no components remaining. Photos taken for documentation.

Inspection & Validation#

With all components removed, the following checks were performed:

  • Motherboard inspected for physical damage, corrosion, or manufacturing defects — none found
  • CPU socket pins examined under lighting — all pins intact and straight
  • RAM slots checked for debris or bent contacts — clear
  • M.2 slots and SATA connectors verified — all functional
  • Thermal paste condition noted on CPU and cooler — reapplication planned

Reassembly#

Components reinstalled in forward dependency order:

  1. Power supply — Aligned to rear case mount, slid into position, secured with three screws
  2. Power cables routed — 8-pin ATX and 4-pin CPU cables run through cable management clips before connection to motherboard
  3. CPU installed — Aligned using notches on LGA1700 socket, seated flat, retention lever closed and locked
  4. Thermal paste applied — Small dot applied to CPU heat spreader center (not spread — cooler pressure distributes it)
  5. CPU cooler installed — Secured to mounting points, fan power connector attached to CPU_FAN header
  6. RAM installed — Module seated in DIMM Slot 1 (single-channel configuration), clips locked
  7. M.2 NVMe SSD installed — Drive inserted at angle into M.2 socket, pressed down, retention screw reinstalled (critical step)
  8. Case cover reinstalled — Aligned and secured

Post-Build Validation#

System powered on. BIOS POST successful. All components detected:

  • CPU: Intel Core i5-14500 recognized
  • RAM: 16 GB DDR5 detected at 4400 MHz
  • Storage: M.2 NVMe SSD visible in BIOS storage menu
  • Cooling: CPU fan operational, RPM reported in BIOS

System proceeded to OS installation without issue.

Outcome#

Complete teardown and rebuild executed successfully. Every component removed, inspected, and reinstalled. System functional, stable, and validated at the BIOS level before OS deployment.

This is foundational work. Understanding how a system is built — not just that it works — is what makes troubleshooting, upgrading, and recovery possible later.

Post-Build Upgrades#

After initial build validation, the system was upgraded beyond baseline configuration:

Memory Upgrade#

  • Added: 2x Corsair Vengeance DDR5 DRAM 16GB modules (6400 MHz)
  • Retained: Original 16GB DDR5 module from Dell
  • Total Memory: 48GB DDR5 (mixed configuration: 2x 16GB Corsair @ 6400MHz + 1x 16GB Dell @ 4400MHz)
  • Configuration: Multi-channel operation, system clocks all modules at lowest common speed (4400MHz) for stability

Storage Expansion#

  • Added: WD Blue SN5000 2TB NVMe SSD
  • Slot: Secondary M.2 PCIe slot
  • Configuration: Assigned as D: drive, fully encrypted with BitLocker for secure secondary storage
  • Use Case: Isolated environment for sensitive data and project work requiring encryption at rest

Both upgrades installed without issue. System recognized all components immediately, no BIOS reconfiguration required.

Why It Matters#

You can't fix what you don't understand. A teardown isn't just disassembly — it's a forcing function for systems thinking. Every connector, every screw, every dependency becomes part of your mental model of how the machine actually works.

When something breaks later — and it will — you'll know exactly where to start.
