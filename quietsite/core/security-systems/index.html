Security Systems & Hardening#

Overview#

This section documents real-world system security work across personal infrastructure, enterprise-style labs, and hardened production endpoints. Work spans endpoint hardening, identity controls, monitoring, and secure network design.

Endpoint Hardening#

  • Windows 11 hardening (ransomware protection, exploit mitigation, controlled folder access)
  • Application control and service minimization
  • Secure boot, BitLocker, firmware-level protections
  • Event log tuning for privilege escalation, persistence, and lateral movement
  • Defensive rebuilds following instability or misconfiguration

Identity & Access Control#

  • Role-Based Access Control (RBAC) design
  • Least-privilege enforcement across systems
  • AAA / TACACS+ concepts applied in lab and organizational contexts
  • Account lifecycle management and access auditing

Security Monitoring & Detection#

  • Custom Windows Event Viewer filters
  • IOC identification and documentation
  • Alert triage and false-positive validation
  • MITRE ATT&CK–aligned investigation workflows
  • SOC-style incident documentation using structured Markdown

Secure Network Design (Integrated)#

  • Segmented networks (private, guest, IoT)
  • VLAN-aware architecture
  • Router hardening and firewall rule design
  • Mesh network optimization based on heat-mapping
  • Secure Wi-Fi configuration (hidden SSIDs, band management)

Cryptography & Data Protection#

  • Disk encryption and secure storage practices
  • Hashing and encoding analysis
  • Data recovery with chain-of-custody awareness
  • Secure handling of rescued storage media

Evidence & Documentation#

  • Photo-documented builds and hardening steps
  • Configuration screenshots and change records
  • Long-term archival of systems work (digital + physical)
  • Cross-referenced with Operation Hard Dell and Systems Archive
