Surfer

TryHackMe CTF. Surfer bro themed web app with internal-only functionality and an export PDF button that reads server-side URLs. The synopsis says only some functionality is internal-use, but if you catch the right wave, you can probably find the sweet stuff. Challenge accepted.

Recon

nmap -A -T4 -p- TARGET_IP

Open ports:

  • Port 22: SSH
  • Port 80: HTTP

Shoutout to robots.txt and /backup/chat.txt here, as well as login.php. Let’s tango.

With port 80 open, I ran a deeper enumeration of the web app with feroxbuster, aka Ferric Oxide:

feroxbuster -u http://TARGET_IP -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt -x php,html,txt -t 50 -o ferox_surfer_out.txt

I love watching this run.

Ferox scan isn’t complete yet, but we’ll evaluate the results once it is. We have plenty to get started with.

The export pdf button points to http://TARGET_IP/export2pdf.php and generates reports for http://127.0.0.1/server-info.php.

So we have a loopback IP, and feroxbuster is still not done. /internal is what I’m looking for. I’ll have to run this with a new wordlist because I don’t have that kind of time.
